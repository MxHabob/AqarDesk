# Email

Shared React Email templates and the Resend delivery adapter for AqarDesk.
Templates support Arabic RTL and English and use the same branded layout for
welcome, sign-in verification, staff invitation, support, and listing-update
messages.

The package never reads environment variables or stores provider credentials.
Applications configure `createResendEmailProvider` with server-side
`RESEND_API_KEY` and `EMAIL_FROM`. Action URLs must be absolute HTTP(S) URLs
generated by the server from the canonical application origin.

The web app stores outbound mail in the database outbox. Configure an external
scheduled job to POST to `/api/cron/email-outbox` with
`Authorization: Bearer <CRON_SECRET>`. The worker sends a bounded batch,
expands campaign recipients in batches of 100, retries transient failures, and
uses the outbox deduplication key as the provider idempotency key. Listing
updates are sent only to verified users who opted in before the campaign was
created, include one-click unsubscribe headers, and recheck the preference
immediately before delivery. Saving a listing only writes a campaign record;
it never waits for recipient expansion or provider delivery.
